## 场景

把一个本地 Hexo 博客调整为 AI 技术知识库，并通过 GitHub Pages 发布。

## 推荐流程

1. 先在本地修改主题和内容结构。
2. 本地构建并打开预览地址验证。
3. 确认无误后再提交和推送。
4. 由 GitHub Actions 自动部署公网版本。

## 验收方式

- 首页可以快速进入博客、文档、示例、帮助和源码。
- 文档页具有目录和前后章节跳转。
- 搜索、分类、标签和归档入口可用。
